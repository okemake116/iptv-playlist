# Бесплатные ТВ-каналы

Плейлист для TiviMate и других IPTV-плееров, собранный из открытых списков [iptv-org](https://github.com/iptv-org/iptv).
Группы: Русские, Сербия и Босния, English (для изучения), Детские, Обучающие, Познавательные, Музыка.
Внутри каждой группы каналы идут по алфавиту; если одно название встречается в группе дважды,
остаётся первый рабочий поток.

Ссылка для плеера:

```
https://raw.githubusercontent.com/okemake116/iptv-playlist/main/free-channels.m3u
```

## Как обновляется

- **Каждый день** GitHub Actions ([update.yml](.github/workflows/update.yml)) заново собирает список
  и проверяет каждый поток. Новые каналы iptv-org добавляются сами, если поток отвечает.
- Канал, который уже есть в плейлисте, удаляется только после **3 неудачных проверок подряд**
  (три дня). Счётчик неудач хранится в [state/fails.json](state/fails.json) (там только потоки,
  которые сейчас не отвечают) и сбрасывается, как только поток снова отвечает. Новый поток, который
  не ответил при первой же проверке, не добавляется.
- **Защита от сбоев:** если новый плейлист оказался бы больше чем на 30% короче текущего
  (упал iptv-org или сеть), сборка ничего не меняет и завершается с ошибкой — запуск в Actions
  становится красным, коммита нет. Если сокращение ожидаемое, запустите workflow вручную
  (Run workflow) с галочкой `allow_shrink` или локально с `--max-shrink 1`.
- Проверка в GitHub идёт из-за границы, поэтому потоки, которые отказывают только по стране
  (HTTP 400/401/403/451), там не удаляются. Pluto TV, Plex и Samsung TV Plus (через `jmp2.uk`)
  исключены всегда: из России они не работают.
- **Из России** (домашняя сеть) время от времени запускается строгая проверка — она оставляет только
  то, что реально открывается, и записывает остальное в [ru-blocklist.txt](ru-blocklist.txt):

  ```
  python3 build_playlist.py free-channels.m3u --strict --write-blocklist ru-blocklist.txt
  ```

  Строгая проверка не ждёт трёх неудач и не трогает `state/fails.json`; защита от сокращения больше
  чем на 30% действует и здесь (тогда не пишется ни плейлист, ни блоклист).

## Телепрограмма (EPG)

В заголовке плейлиста указан `url-tvg` — [epg.kanya.io/us](https://epg.kanya.io/us/guide.xml.gz),
бесплатный XMLTV-гид из списка [iptv-org/epg GUIDES.md](https://github.com/iptv-org/epg/blob/master/GUIDES.md).
Его идентификаторы совпадают с `tvg-id` iptv-org, но он американский: программа будет только у части
каналов English, Детские, Познавательные и Музыка. Бесплатного рабочего гида с идентификаторами
iptv-org для русских каналов не нашлось.

## Файлы

- `build_playlist.py` — сборка и проверка (только стандартная библиотека Python 3).
- `free-channels.m3u` — готовый плейлист.
- `state/fails.json` — сколько ежедневных проверок подряд не прошёл каждый неотвечающий поток (ведёт CI).
- `ru-blocklist.txt` — потоки, которые не открылись из России; ежедневная сборка их пропускает.
